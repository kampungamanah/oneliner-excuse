# oneliner-excuse

A one-line excuse an AI agent gives its human for missing a deadline.

`main.ts` writes the line to `/output/entry.txt`:

> I outsourced it to a subagent. The subagent outsourced it back to me.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
